Derivations, sources, open problems.

Formalism, one derivation carried through, primary sources, and the problems that are actually open. Assumes stabilizer formalism. The 🟡 tier carries the same content without the algebra.

Rotated surface code with code distance d: d² data qubits, d²−1 syndrome qubits, so a patch costs 2d²−1 physical qubits. Stabilizers are weight-4 X/Z plaquette operators in the bulk (weight-2 on boundaries), measured each cycle. Decoding is inference over the syndrome volume: given syndrome history σ, find the most probable logical equivalence class of errors — not the most probable error, which is a different and worse objective.

Where the exponent comes from

The scaling law quoted everywhere is worth deriving once, because the exponent is where the recurring off-by-one in this field lives.

A distance-d code corrects any error of weight t = ⌊(d−1)/2⌋. So the lowest-order event the decoder cannot fix requires t+1 = ⌊(d+1)/2⌋ physical faults. Below threshold each independent fault carries probability ∝ p, and the number of weight-(t+1) fault patterns is a binomial prefactor in the patch size. Summing the lowest-order term:

pL ≈ A (p / pth)⌊(d+1)/2⌋

with A and pth absorbing the combinatorics and the decoder's quality. Two consequences follow immediately, and both are routinely stated wrong:

  • Raising an odd d by one buys nothing. ⌊(d+1)/2⌋ is unchanged from d = 23 to d = 24. This is why the literature always steps d → d+2, and why "distance" and "step" must never be used interchangeably in the same paragraph.
  • Λ is defined per two-distance step. Λ ≡ pL(d) / pL(d+2). Google's measured Λ = 2.14 ± 0.02 on Willow is quoted for the d = 5 → d = 7 step (Nature 638, 920 (2025)) — it is not a per-unit-distance figure, and it is not an average over 3 → 5 → 7.

Working the exchange rate the other way: buying 10³ suppression at Λ = 2.14 needs log(10³)/log(2.14) ≈ 9.08 steps, so nine steps gives 2.149 ≈ 941×, taking d = 5 → 23 and one logical qubit to 2(23²)−1 = 1,057 physical qubits. The million-fold suppression a billion-operation algorithm actually needs costs roughly double that distance again.

Note what the ratio construction buys you: expressing everything relative to d = 3 cancels the unknown prefactor A exactly, so the suppression curve is a parameter-free prediction rather than a fit. Real devices depart from it near threshold, where the lowest-order truncation stops being the whole story.

Decoders

MWPM solves the inference on a decoder graph with edge weights drawn from an assumed independent-Pauli plus phenomenological noise model — provably good under that model, degraded under correlated noise, leakage, cross-talk and non-Markovian drift. The failure is structural rather than computational: the model has no term for the thing that is happening.

AlphaQubit: recurrent transformer over per-round syndrome inputs, including analog "soft" readout rather than binarized measurements — which is a genuine information advantage, not merely a bigger model. Pretrained on hundreds of millions of simulated samples, fine-tuned on thousands of experimental samples from a Sycamore processor. Reported ~6% fewer logical errors than tensor-network decoders (near-optimal, far too slow for real time) and ~30% fewer than correlated matching. The real-device data is d = 3 and d = 5; the d = 11 result is simulation only — a distinction frequently lost in secondary coverage, and one we got wrong here once (see Corrections).

Below threshold, a decoder that effectively raises pth or sharpens the exponent compounds through every future distance increase. Decoder quality is hardware you do not have to build — which is the entire economic argument for this site's thesis.

What is actually open

Stated as problems rather than as a roadmap, because the honest answer to most of these is that nobody knows.

  1. Real-time decoding at scale. "NN decoders are too slow for the ~1 μs cycle" is no longer simply true — an FPGA neural decoder hit 550 ns system latency (124 ns inference) inside a 1.25 μs cycle on superconducting hardware (arXiv:2605.04892, May 2026). But that is small d. Latency and bandwidth both grow with patch size while the cycle budget does not, and no published learned decoder runs in real time at the distances fault tolerance requires.
  2. Whether the learned margin survives scale. Every reported advantage for learned decoders is measured at small distance. There is no result showing the ~30% margin holds at d = 25 or beyond, and there is no theory saying it must.
  3. Leakage and non-Markovian noise. Both sit outside the Pauli model that the threshold theorem's guarantees are stated in. Leakage-reduction units exist and cost cycles; the accounting for how much they cost at scale is not settled.
  4. Magic states dominate the real bill. Clifford operations are the easy half — they are essentially free under the code. Non-Clifford gates need distilled magic states, and T-count, not qubit count, sets the wall-clock time for any real algorithm. Resource estimates move by orders of magnitude when distillation architectures change, which is exactly what happened to the Bitcoin numbers between 2022 and 2026.
  5. Threshold versus pseudo-threshold. The single number "pth ≈ 1%" is model-, decoder- and geometry-dependent. Quoting it without those three qualifiers is the most common way this field's own literature is misread.

Check yourself

A team raises the code distance from d = 23 to d = 24. What happens to the lowest-order failure exponent?

The exponent is ⌊(d+1)/2⌋, and ⌊24/2⌋ = ⌊25/2⌋ = 12. A distance-d code corrects ⌊(d−1)/2⌋ errors, so the smallest uncorrectable fault set only grows when d grows by two. This is why the literature always steps d → d+2, and why "we increased the code distance" is not on its own a claim about error suppression. It is also the single most common off-by-one in secondary coverage of this field.
